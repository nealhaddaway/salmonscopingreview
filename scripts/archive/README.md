# Archived / legacy scripts

This directory is reserved for superseded development scripts that remain useful for reproducibility or audit purposes but are not part of the current production workflow.

## Policy

- Do not delete historical scripts merely because a newer version exists.
- Move a script here only after confirming that no production script sources it and that its outputs are not required to reproduce the frozen historical master.
- Preserve the original filename and, where useful, group by workflow (`geography/`, `topics/`, `relevance/`, etc.).
- The canonical production pipeline is documented in `scripts/PRODUCTION_PIPELINE.md`.
